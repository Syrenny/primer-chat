# Primer Chat

> Общая идея: Хотелось бы просматривать PDF-документы и задавать по ним вопросы в чате рядом

## Front

### Требования

-   Быстрая загрузка в Real-Time
-   Интеграция с OpenAI GPT4o
-   PDF Viewer
-   Отображение найденных фрагментов
-   Отображение процесса индексации в реальном времени
-   Кэширование файлов

### Фичи

-   Минималистичный кастомный PDF-viewer
-   Отображение найденных фрагментов в PDF-viewer с возможностью итерироваться по ним
-   Возможность объединять файлы в папки. Отдельная кнопка создать проект, затем дать ему имя и можно перетаскивать туда файлы из корня
-   Возможность запоминать информацию о пользователе, предпочтения, подстраиваться под него + делать по ходу саммари по проектам/отдельным файлам
-   Возможность порассуждать над проблемой
-   Авторизация по API ключам, по ним же контролировать доступ к моделям, функционалу, лимиты и т.д.

### Стек

React + ts + vite + Dexie.js/idb (IndexedDB дял кэширования файлов) + zustand (стейты с персистом) + shadcn для UI

## Backend

### Требования

-   Многопользовательский режим
-   Асинхронный
-   Хранение файлов в S3
-   Хранение остальной информации в PostgreSQL
-   Стриминг ответов от системы
-   Горизонтальное масштабирование воркеров для индексации и генерации

### Фичи

-   Поддержка пайплайна для рассуждения
-   Поддержка рассуждающих моделей
-   Kafka?

### RAG-индексация

1. Чтение PDF с помощью fitz/PDFplumber или другой библиотеки
2. Находим top-n вариантов форматирования
3. Загружаем их в GPT4o для определения тегов html для каждого форматирования
4. Таким образом получено первичное разделение на структурные элементы
5. Теперь рекурсивно проходим семантическим делением по длинным элементам

### Стек

Go для API, CRUD + Python для воркеров на Redis + S3 + PostgreSQL
